## Reporting a Vulnerability

We take the security of `project_cri` seriously. If you discover a security vulnerability, please report it responsibly using the guidelines below.

### Where to Report
* **Private Vulnerability Reporting:** If available on this repository, please use GitHub's **Private Vulnerability Reporting** feature (found under the **Security** tab of the repository) to disclose the issue privately.
* **Email:** Alternatively, you can send an email to your primary development contact or maintainer email. **medbelmaizi@gmail.com**

### What to Include in Your Report
To help us triage and fix the issue as quickly as possible, please provide:
* A description of the vulnerability and its potential impact.
* Step-by-step instructions or a minimal code example to reproduce the issue.
* Any relevant logs, screenshots, or configuration details.

### Response Timeline
* **Initial Response:** You can generally expect an acknowledgment of your report within **48 hours**.
* **Status Updates:** We will keep you informed about our progress as we investigate and develop a fix.
* **Public Disclosure:** Once a fix is deployed, we will coordinate public disclosure with you if appropriate.

Thank you for helping keep `project_cri` safe and secure!
